# 坦克大战外星人 3D (Tank vs Aliens 3D)

一款用 Python + [Ursina](https://www.ursinaengine.org/) 引擎开发的简单 3D 射击游戏。
你驾驶一辆坦克，保卫地球，击退从四面八方袭来的外星飞碟与地面外星人军队。

所有 3D 物体都由引擎内置几何体（立方体 / 球体）程序化拼搭而成，所有音效由
`numpy` 本地合成生成 —— **无需联网下载任何素材**。

---

## 玩法

- **W A S D**：控制坦克向前 / 左 / 后 / 右移动（车体自动转向移动方向）
- **移动鼠标**：3D 瞄准 —— 把准星移到目标上即可，炮管会自动抬起对准空中的飞碟。
  准星**压住敌人时会变成红色 `X`**，表示已锁定，开火即可命中。
- **鼠标左键**：开火，发射炮弹（可按住连发）
- **Esc**：返回主菜单

### 敌人
- **飞碟 (UFO)**：在空中盘旋逼近，并向你发射红色等离子弹（需 2 发击落，150 分）
- **地面外星人**：成群冲向坦克，接触即对你造成伤害（1 发击杀，50 分）

随着时间推移，敌人刷新速度会逐渐加快。坦克生命值（左上角血条）归零即游戏结束。

## 运行方法

### 1. 准备 Python 环境
建议使用 **Python 3.11**（Ursina 依赖的 panda3d 对过新的 Python 版本可能暂无预编译包）。

### 2. 安装依赖
```powershell
pip install -r requirements.txt
```

### 3.（可选）重新生成音效
仓库已经包含生成好的音效；如需重新生成：
```powershell
python generate_sounds.py
```

### 4. 启动游戏
```powershell
python main.py
```

> 本机说明：开发时使用的是 Anaconda 的 Python 3.11，可直接用
> `& "D:\anaconda\python.exe" main.py` 启动。

在主菜单点击 **START GAME** 开始，点击 **QUIT** 退出。

## 项目结构

```
new/
├── main.py              # 入口：主菜单 / 游戏结束界面 / 场景切换
├── game.py              # 游戏核心：场景、刷怪、碰撞、HUD、相机、胜负
├── entities.py          # 实体：坦克、子弹、飞碟、地面外星人、爆炸特效
├── audio.py             # 音效播放封装
├── generate_sounds.py   # 用 numpy 合成所有音效（写入 assets/sounds/）
├── requirements.txt     # 依赖清单
├── README.md            # 本文件
└── assets/
    └── sounds/          # 生成的 .wav 音效
```

## 技术要点

- **视角**：固定俯视斜角的第三人称相机，平滑跟随坦克。
- **瞄准**：一块不可见的水平碰撞平面，通过鼠标射线交点确定炮塔朝向，做到“指哪打哪”。
- **碰撞**：采用简单的距离判定（而非物理引擎），轻量且稳定。
- **音效**：`generate_sounds.py` 用正弦波、噪声和包络合成开火、爆炸、击中、
  受伤、点击、游戏结束音效以及一段循环背景音乐。
